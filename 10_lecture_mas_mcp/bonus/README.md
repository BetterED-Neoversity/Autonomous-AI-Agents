# Бонус: той самий кейс в інших фреймворках

Обидва файли — довідкові. На занятті вони не запускаються: тягнуть важкі
залежності й окремі ключі. Потрібні вони для ДЗ-3, де вимагається друга
реалізація MAS і порівняльна таблиця.

| Файл | Фреймворк | Як інтегрується MCP | Установка |
|---|---|---|---|
| `mas_crewai.py` | CrewAI | `MCPServerAdapter` (або поле `mcps` в `Agent`) | блок «БОНУС» у `requirements.txt` |
| `adk_mcp_agent.py` | Google ADK | `McpToolset` у списку `tools`, `tool_filter` як allowlist | блок «БОНУС» у `requirements.txt` |

Обидва файли читають той самий `.env`, що й основне демо, і піднімають той
самий `mcp_server.py`. Шляхи рахуються від `__file__`, тому запускати можна
і з кореня демо, і з цієї папки.

Окреме оточення не потрібне: версії бонусних пакетів підібрані так, щоб
жити поруч з демо (`pip check` чистий, тести демо зелені). У класі рядки
закоментовані, бо тягнуть близько гігабайта. Щоб спробувати:

    # у requirements.txt розкоментувати блок «БОНУС»
    .venv/bin/pip install -r requirements.txt
    .venv/bin/python bonus/mas_crewai.py
    .venv/bin/python bonus/adk_mcp_agent.py

ADK-версія працює headless — `Runner` + `InMemorySessionService`, без UI:
друкує виклики MCP-tools і фінальну відповідь українською. Шлюз
OpenAI-сумісний, тому в обох файлах модель підключено не нативним клієнтом
фреймворку, а через LiteLLM з моделлю `openai/<LLM_MODEL>`. `adk web` —
окремий необов'язковий шлях: `root_agent` лишено на рівні модуля, щоб UI міг
його підхопити, але на занятті він не використовується.

## Що саме порівнювати в ДЗ-3

Не «зручність», а перевірювані речі:

| Критерій | LangGraph | CrewAI |
|---|---|---|
| Рядків коду на той самий кейс | більше | менше |
| Контроль маршрутизації | явні ребра графа | вирішує менеджер-агент |
| Куди вставити guardrail на tool | будь-де у вузлі | обгортка інструмента |
| HITL | `interrupt()` + checkpointer | human input, менш гнучко |
| Відтворюваність прогону | висока (стан явний) | нижча (делегування — рішення LLM) |
| Токенів на звернення | менше (немає діалогу менеджера) | більше |

Числа беріть зі свого прогону, а не з таблиці: замір робиться трасуванням
(крок 7) або лічильником usage у відповіді моделі.
